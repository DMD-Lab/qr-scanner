# QR Scanner — DMD Lab

Scanner de QR codes et codes-barres, sans pub, sans compte. Fait une chose, bien : scanner — sans interruption.

[Voir la roadmap →](ROADMAP.md)

## Pourquoi cette app

Les scanners existants affichent des publicités plein écran ou persistantes entre chaque scan, rendant l'usage quotidien pénible. QR Scanner fait une chose, bien : scanner — sans interruption.

## Stack

Flutter · Riverpod · GoRouter · mobile_scanner · sqflite

## Couleurs

Primaire indigo `#6366F1`

## Fonctionnalités

- Scan en temps réel (QR, code-barres)
- Détection de type : URL, texte brut
- Avertissements HTTP / URL raccourcie
- Historique des scans
- Deux modes : affichage manuel ou ouverture automatique
- Dark / light mode

## Lancer le projet

```bash
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```
